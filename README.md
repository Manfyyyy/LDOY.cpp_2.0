# Survival 2D — порт на C++ + SFML

Порт старого проекта с TXLib.

## Структура папки

```
LDOY.cpp_2.0/
  main.cpp
  CMakeLists.txt
  textures/
  assets/font.ttf  (необязательно, любой .ttf; иначе берётся Arial/DejaVu из системы)
```

## Сборка (Windows, Visual Studio 2019+ или любой компилятор + CMake)

```
cmake -S . -B build
cmake --build build --config Release
```

SFML 2.6.1 скачается и соберётся сам (нужен интернет при первой сборке).
Запускайте exe из папки, где лежит `textures/`.

## Управление

- A / D — ходить, W / S — вверх/вниз (только на 2-й локации)
- ЛКМ по машине рядом с ней — обыскать
- На 2-й локации: ЛКМ по стене 10 раз — сломать, затем ЛКМ по вагону
- E — инвентарь, Esc — пауза / закрыть инвентарь
- Белый цвет в .bmp считается прозрачным, как в TransparentBlt

## Что изменилось по сравнению со старой версией

- Нет TXLib, Windows API и мусора с `txSleep`: движение зависит от времени, а не от кадров
- Тексты в UTF-8 вместо cp1251
- Лут машины и вагона — один общий код вместо двух копий
- Анимация ходьбы использует все 6 кадров
- Пистолет и патроны теперь реально выдаются (машина даёт пистолет, вагон — патроны)
- Клики обрабатываются как события, без дребезга
